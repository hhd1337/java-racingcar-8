# 우테코 프리코스 2주차 미션 - 자동차 경주 🚗💨
<br>

## 구현할 기능 목록

### 입력
- 자동차 이름을 입력받는다.
- 시도 할 횟수를 입력받는다.

### 입력 검증
- 자동차 이름 입력 시
  - 콤마로 구분 후 각 이름을 trim() 처리한다.
  - 잘못된 입력값에 IllegalArgumentException 발생시킨다. (빈 문자열, 공백만 입력, 중복이름, 5자초과 이름 입력 등)
- 시도 할 횟수를 입력 시
  - 잘못된 입력값에 IllegalArgumentException 발생시킨다. (0 이하 정수, 비정수 문자열, 너무 큰 값 등)

### 경주 로직
- 전진조건 : 0~9 랜덤 값 중 4 이상일 때 전진.
- 한 라운드 실행 시 모든 자동차에 대해 난수 생성하고, 한칸 전진 또는 정지시킨다.
- 총 n회 라운드를 수행한다.

### 출력
- 라운드별 실행결과를 해당 라운드가 끝남과 동시에 곧바로 출력한다.
- 가장 마직막으로 우승자를 출력한다. (공동 우승자는 ','로 구분하여 출력한다.)

### 우승자 판별
- 모든 라운드 종료 후 우승자 판별 로직(누적거리 합이 가장 큰 사람이 우승자)에 따라 우승자를 가린다.
